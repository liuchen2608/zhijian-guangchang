3. 补摄像头会话竞争测试：旧的 video.play 返回只能回收旧流，不能关闭新流。
4. 修复测试工具审计问题、非有限结果校验、帧转移失败的 bitmap 释放。

## 本人最短验收路径

1. 在 Chrome 打开 http://localhost:5180/，点击「启用摄像头」并授权。
2. 伸食指移动；捏合并拖动；张开五指；伸食指快速摆动。观察对应四种效果。
3. 张开手掌正对镜头保持半秒，再前后移动；必要时点「重新校准纵深」。
4. 把手移出再移回，确认光束平滑恢复。
5. 点击「关闭摄像头」，确认设备关闭；重新开启验证可重复使用。
6. 若卡顿，选择轻量并展开底部性能区域；记录实际数值和操作现象。

反馈提供动作、错误码、画质和浏览器版本即可，无需上传个人录像。开发服务器 5180 保留供本轮验收，测试服务自行关闭；结束预览后可在启动终端按 Ctrl+C。
