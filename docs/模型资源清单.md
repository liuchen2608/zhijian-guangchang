# 模型资源清单

第一阶段使用 Google MediaPipe Hand Landmarker（float16，资源路径版本 1），SDK 0.10.32；WASM 从同版本 npm 包复制。来源、准备时间、实际大小和 SHA-256 均见 [model-assets.json](model-assets.json)。模型约 7.5 MB，WASM 两个变体合计约 21 MB。

模型保存在 public/models，WASM 保存在 public/wasm，由 localhost 同源提供。Worker 源码在 src/tracking/hand.worker.ts，构建产物 public/tracking-worker.js 由 esbuild 生成，dev/build 自动更新。没有运行时 CDN 请求或视频上传。

SDK npm 包标识 Apache-2.0；当前安装包没有独立 LICENSE 文件；可参考官方仓库许可 https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE。模型来源为 Google 官方下载地址；模型卡地址随 JSON 清单记录。后续公开分发前应按具体模型卡和平台要求复核许可。

运行 `npm run prepare:assets` 可补齐资源并更新本地哈希清单。构建前用清单核对实际文件；哈希记录用于定位版本，不是对官方签名的验证。
